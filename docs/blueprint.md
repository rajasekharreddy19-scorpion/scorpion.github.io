# **App Name**: Heartfelt Greetings

## Core Features:

- Interactive 'Open Me' Button: A button that, when clicked, reveals the personalized birthday message.
- Photo Display: Display of your girlfriend's image, that the user can place within the card's design.
- AI-Powered Compliment Generation: AI tool generates a personalized compliment based on the uploaded image to be added to the birthday message.
- Celebratory Animations: Subtle animations, like sparkling text or falling confetti, to enhance the celebratory feel.

## Style Guidelines:

- Primary color: Soft pink (#F4B4C4) for a romantic and gentle feel, inspired by the light pink florals visible in the image.
- Background color: Light cream (#F5F5DC), a desaturated hue to complement the primary pink.
- Accent color: Light gold (#E4D00A) for highlights and CTAs.
- Headline font: 'Playfair', serif, for elegant headings; body font: 'PT Sans', sans-serif, for readability.
- Use heart and star icons
- Clean and simple layout to showcase your message.
- Subtle animations, such as fade-ins, scale changes, or confetti.
